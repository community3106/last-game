私たちについて (About Nostr ASCII Arcade)

中央集権型サーバーのログインやパスワード管理を排除し、Nostrの暗号公開鍵（npub）とWebAssembly（WASM）によって実現された、世界初のエンドツーエンド暗号化レトロゲームアーケードです。

🦀

100% Rust & Leptos Frontend

フロントエンドUIは最新のRustフルスタックフレームワークLeptos（Fine-grained reactivity）を採用。Virtual DOMを介さず、ネイティブWASMによる超高速レンダリングと60 FPS物理演算エンジンをブラウザ上で実現しています。

  • ✔ ゼロコスト抽象化とメモリ安全性
  • ✔ Trunkによる高速WASMバンドル
  • ✔ Web Audio APIによる8-bitチップチューン内蔵シンセ
⚡

Nostr (nostr-sdk / nostro2) as Back

ユーザー認証・セッション・ランキング・チャット・コンテンツ配信はすべて分散型プロトコルNostrで完結。検閲耐性のある公開リレーネットワークを通じてデータを同期します。

  • ✔ Ed25519 / Schnorr署名による自己主権型アイデンティティ (npub)
  • ✔ NIP-07 ブラウザ拡張機能 (Alby, nos2x) のシームレス連携
  • ✔ Kind 30078によるハイスコア分散保存
🔐

公開鍵ホワイトリスト ＋ 暗号化（NIP-04 / NIP-44）

Stripeなどで決済を完了したユーザーの公開鍵（npub）を「有料会員ホワイトリスト」に自動登録。有料限定ステージ（World 1-4など）やチートデータは、購入者の公開鍵向けにDiffie-Hellman ECDH暗号化してリレーに投げるため、無料ユーザーには中身を絶対に解読できません。

  • ✔ NIP-04: AES-256-CBC 共有秘密暗号
  • ✔ NIP-44 v2: HKDF + ChaCha20-Poly1305 認証付き暗号
  • ✔ クライアントサイドでの秘密鍵（nsec）即時復号
☁️

Cloudflare Pages & GitHub Actions CI/CD

GitHub Actionsによる自動テスト・WASMビルドを経て、Cloudflare Pagesのエッジネットワークにグローバル即時デプロイ。CLOUDFLARE_API_TOKEN と CLOUDFLARE_ACCOUNT_ID による安全なCI/CDパイプラインを確立しています。

  • ✔ エッジサーバーによる低レイテンシ配信
  • ✔ セキュリティヘッダー（CSP, FrameGuard）適用
  • ✔ 完全自動化されたプッシュ時デプロイ
